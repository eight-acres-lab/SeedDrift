# 表模型（实验）

这是一个实验方向，还没有接入分析流程。结果见 [RESULTS.md](RESULTS.md)，由 `report.py` 从运行文件生成。

## 想法

把问题重新表述成一张表：一个基因组的基因是列，参考基因组是行，格子里是这个基因在那个参考基因组里的同源序列。

- 垂直遗传的基因，各列与各行的远近关系是一致的：相似度大致等于“这个基因的进化速率”乘以“这个基因组到那个参考基因组的距离”。
- 水平转移的基因是其中少数不一致的列：它与各行的远近关系像是出自另一个基因组。
- 模型的任务就是在这张表里判断，查询的那一列与其余的列是否出自同一个基因组。

输入里没有分类学，没有比特分和 E 值，也没有“本源类群”这样的人为设定。参考基因组是匿名的行。

## 输入

- **一个样本：** 一个查询基因，加同一基因组的 12 个基因，对同样的 32 个参考基因组。
- **格子的内容：** 该基因在那个参考基因组里的最佳同源序列，与基因做局部比对后按基因的坐标逐残基给出。每个基因读至多 384 个位置。
- **行怎么选：** 12 行是离这个基因组最近的参考基因组，12 行在其余距离范围内均匀抽取，8 行是查询基因自己相似度最高的参考基因组。
- **基因组到参考基因组的距离：** 由基因组自己的基因算出（稳健的秩一拟合），不用分类学。只有至少十分之一的基因在某个参考基因组里有同源时才算有距离，这样一小块外来基因不能把一个参考基因组拉到“最近”。
- **参考基因组的范围：** 从 8,475 个参考基因组里随机抽 2,048 个作面板。

## 训练信号

- **问题：** 查询基因是否与其余 12 个基因出自同一个基因组。
- **“是”的例子：** 同一基因组的另一个基因。
- **“否”的例子：** 另一个参考基因组（供体）的真实基因，放在这个基因组的行上看。
- **隐藏：** 基因组自己总是被隐藏。再随机隐藏它最近的若干行（0 到 32），模拟近缘没有被测序的情形。供体周围同样隐藏。答案为“是”的例子也抽一个供体并同样隐藏，使两类例子只在查询基因本身有差别。
- **混杂：** 12 个基因里随机有 0 到 4 个来自别的基因组，其中一半情况下来自查询的供体。真实基因组里外来基因常常成片出现。
- 不需要任何转移标签。

## 模型

- 每个基因内部，沿着行做注意力；每一行内部，沿着基因做注意力。
- 行与行之间有一个成对的状态：取基因组各基因里“成员对成员”关系的共识，作为注意力的偏置。
- 直接输出两样东西：查询基因是外来的概率；指向“离它真正来源最近的那一行”的指针。

## 比较的几种输入（同一个主干）

| 名称 | 两条比对序列之间的关系怎么给 | 给哪些关系 |
|---|---|---|
| 数值，基因对成员 | 固定的汇总数值：一致度、覆盖度、替换矩阵得分等六个 | 只有基因与它的各个成员 |
| 数值，全部成对 | 同上 | 再加每个基因内部成员与成员之间，以及它们在各基因间的共识 |
| 残基，基因对成员 | 上面的数值，加上由比对的残基学出来的关系 | 只有基因与它的各个成员 |
| 残基，全部成对 | 同上，并能看到每个位置在各成员间的分布 | 全部 |

“残基”一栏在训练开始时与“数值”完全相同，学出来的部分从零长出。所以它是“数值”的超集。

对照：

| 名称 | 用途 |
|---|---|
| 只看有无格子 | 地板：不读任何关系，只知道哪些格子存在 |
| 只看有无格子，带成对机制 | 成对机制本身（不含任何关系内容）带来多少 |
| 遮住查询 | 行的选择本身泄露多少：查询的格子全部遮掉 |
| 数值加氨基酸组成 | “残基”一栏能读到氨基酸组成，这个对照看组成单独值多少 |
| 同一批行上的固定规则 | 查询在“最近的 12 行以外”的最高相似度，减去在“最近的 12 行以内”的最高相似度。相当于用数据定本源类群的 Alien Index |

## 事先定下的评估规程

以下在第二版任何结果出来之前写定（2026-11-16）。第一版只跑完了一个配置，随后的审查改动了数据、采样和模型，第一版的数字不再使用。

**数据划分**（沿用 `research/placement` 的划分，分类学只在这里用到）

- 训练：553 个参考基因组，各约 100 个基因。供体也只来自这些基因组。
- 验证：58 个基因组，供体也只来自这 58 个。用来选检查点。
- 测试：71 个基因组，所在的纲整体没有参加训练；供体只来自这 71 个。
- 三个基准受体所在的谱系（47 个基因组）不参加训练，也不参加上面的测试。

**测试用例**

- 每个测试基因组 54 对用例。每一对是一个本源查询和一个外来查询，其余设置完全相同：供体的距离档、基因组周围隐藏的行数（0、4、16）、供体周围隐藏的行数（0、4、16）、混杂基因数（0、0、1、3）。
- 用例由固定的随机种子生成，所有配置打分的是同一批用例。
- 供体的距离档按实测距离划分：近（小于 0.8，通常同目或同科）、中（0.8 到 1.3，同纲或同门）、远（更远或没有可测的距离）。

**两个主要问题**

1. 读残基是否比读汇总数值好：“残基”减“数值”的 AUROC 差，分别在“全部成对”和“基因对成员”两种情形下。
2. 看全部成对关系是否比只看基因对成员好：“全部成对”减“基因对成员”的 AUROC 差，分别在“数值”和“残基”两种情形下。

**判定**

- 每个配置三个随机种子，取平均。
- 差值的 95% 区间按留出的纲重抽样。区间不包含零才算有差别。
- 主要看近供体一档，因为远供体用什么方法都容易。同时报告全部用例。
- 区间包含零时的结论是“在这个规模上看不出差别”，不是“没有差别”。

**基准基因组只作下限检查**

- 三个基准的外来基因都来自别的门或别的域，多数带有模拟的随机替换，阴性里又含受体真实的转移。它们只能说明一个打分有没有严重失效，不能给几种输入排名。
- 没有任何成员出现在所选行里的基因排在最后，与以前各种打分对“没有证据的基因”的处理一致。
- 表模型只读四分之一的参考基因组，以前的打分读全部。

## 规程之后追加的内容

以下三项都是在第二版第一个随机种子的结果出来之后才加的，属于探索，不改变上面的判定。

**语言模型位点（`sites.py`，`--mode plm`）。** 在“残基”一栏的基础上，基因的每个位置再带上蛋白语言模型（ESM-2 650M）在该位点的状态：20 种氨基酸的对数概率，加末层隐状态的 28 个主成分。用途是让模型拿成员的残基去对照“语言模型认为这个位置该是什么”。只跑了一到三个种子，不在事先定下的比较之内。

**不经训练的参照（`ceiling.py`）。** 把保存下来的每条用例原样重建，用几种固定的统计量打分，其中两种被告知供体是谁（不是方法，只用来估计相似度里有多少信号）。它还按两个基因组的画像把用例分层：有没有一行看得见的参考基因组，离供体比离基因组更近，或者反过来。两边都没有时，基因组和供体互为最近邻，所有行离两者一样远，任何方法都分不开。结果在 `results/ceiling_unseen.md`。这个分层是看过结果之后才做的。

**第三版：宽表（`wide.py`）。** 见下一节。

## 第三版：宽表（规程写于它的任何结果出来之前，2026-11-16）

第二版第一个种子的结果和上面的参照指向同一件事：每条用例只给 12 个同基因组的基因，模型要靠这 12 个基因猜出“这个基因组在每一行上正常是什么样”，猜得很粗；成对机制没有带来差别。第三版把力气放在这里：

- 一个样本是同一基因组的 64 个基因，其中一部分（0 到 16 个）被换成一到三个供体的基因。模型对每个基因都给出“是否属于这个基因组”和指向来源的指针。每个基因都有标签，监督信号是第二版的几十倍。
- 行：离基因组最近的 32 行，其余距离范围内均匀抽 32 行，再由各基因自己带入至多 96 行（每个基因带入它相似度最高的两行）。
- 格子的内容是检索给出的比对汇总（得分、一致度、覆盖度、长度比），不再重新比对。因此行可以取自全部 8,475 个参考基因组，不限于面板。
- 隐藏的定义改成半径：基因组（或供体）自己，加上所有不比它第 k 近的面板参考基因组更远的参考基因组。在面板内这与第二版相同。

**两个配置**

| 名称 | 行的来源 |
|---|---|
| 宽表，面板 | 只用面板里的 2,048 个参考基因组，与第二版的信息来源相同 |
| 宽表，全部 | 全部 8,475 个参考基因组 |

**用例。** 直接用第二版保存的用例表：同一个查询、基因组、供体、隐藏档位。查询作为 64 个基因之一，其余基因来自同一基因组，混入别处基因的比例与原用例相同（12 个里 0、1、3 个，对应 63 个里 0、5、16 个）。所以两个版本打分的是同一批查询。

**比较**

1. “宽表，面板”减“数值，基因对成员”：信息来源相同、格子内容同类，差别是同时看多少个基因、是否每个基因都判。
2. “宽表，全部”减“宽表，面板”：行的来源从四分之一扩大到全部。这一项里两边能看到的行不同，不是同等条件下的比较，只说明放开面板值多少。

**判定**

- 指标是没见过的纲上全部用例的 AUROC；同时报告“看得见的行能把供体和基因组分开”的那部分用例（按 `ceiling.py` 的分层，用面板上的行定义，在第三版结果出来之前定下）。
- 差值的 95% 区间按留出的纲重抽样，区间不包含零才算有差别。先跑一个种子；差别明显时再补到三个。
- 检查点按验证集全部用例的 AUROC 选（第二版把近供体一档算进去一半，而那一档大半在原理上不可分）。
- 基准基因组仍只作下限检查。“宽表，全部”读的是全部参考基因组，与以前的打分读的范围相同。

## 已知的局限

- “残基”一栏是按位置独立、学出来的成对打分，在进入主干之前汇总一次。它不是把残基级的状态一直带到网络深处的模型。这一栏如果没有赢，不能说明残基级模型没有用。
- 成对状态只用来引导注意力，自身不被更新。
- 成员相对基因的插入没有保留。长于 384 的基因只读其中一部分位置。
- 近供体一档在留出的纲里用例偏少，各基因组能找到的近缘供体数目不一。
- 每个样本只有一个二分类标签和一个指针，监督信号稀。

## 复现

服务器上需要 torch、numpy、parasail，以及 `research/placement` 的检索结果。

```bash
python research/array/build.py columns --library LIB --hits hits_a.tsv --out DIR/cols_a.npz
python research/array/build.py profile --library LIB --columns DIR/cols_*.npz --out DIR/profiles.npz
python research/array/build.py align --profiles DIR/profiles.npz --columns DIR/cols_a.npz --fasta queries_a.faa --reference reference.faa --out DIR/a
python research/array/fit.py --data DIR --names a b --profiles DIR/profiles.npz --library LIB --out DIR/run2/num_pairs --mode num --pairs 1
python research/array/report.py --runs DIR/run2 --profiles DIR/profiles.npz --library LIB --out research/array/RESULTS.md
```

第三版和参照：

```bash
python research/array/ceiling.py --data DIR --names a b --profiles DIR/profiles.npz --library LIB --which unseen --runs msa_pairs=DIR/run2/msa_pairs --out research/array/results/ceiling_unseen.md
python research/array/wide.py --data DIR --names a b --profiles DIR/profiles.npz --library LIB --trials DIR/run2/num_anchor --out DIR/run3/wide_all --universe all
```

`factor.py` 是同一想法不经训练的版本（直接用秩一拟合的残差打分），结果在 `results/factor_benchmark.md`，效果很差，仅作参照。
