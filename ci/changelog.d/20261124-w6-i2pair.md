# W6: two arms' ends paired by table (round 1's reading i2_pair)

- `rel_w6_report.paired_ends` [{name, first, second, threshold}]: the second arm's end minus the first's on the cells
  both scored (all held-out tables, strictly offline), paired by table with the evaluator's bootstrap over the split
  units, under scattered, whole_gene and suffix, over all tables and by the relatives strata, the blocks apart, against
  the threshold given (protocol round1, version 10, readings.i2_pair (a): strict against online training).

- For i2_pair (a), `strict_online_tables: 3000` verifies each evaluation against the local held-out mask plan before the
  report publishes a paired comparison. The audit records scored tables, cells and position digest for each condition.
  The online repeat uses the strict arm's final checkpoint. Every cell difference under scattered and suffix must be
  smaller than 0.0005 bits in magnitude to read zero at three decimals. The JSON also records the unrounded maximum,
  mean and count of nonzero differences.
