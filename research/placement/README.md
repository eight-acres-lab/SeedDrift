# 归属预测模型（实验）

这是一个实验方向，还没有接入分析流程。

## 想法

参考库里每条蛋白都有已知的谱系。把一条蛋白自己的谱系从检索结果里藏掉，让模型从剩下的同源命中里判断它属于哪一支。这个任务的标签是免费的，数量和参考库一样大，而且“藏到哪一级”可以随机取，模型因此见过近亲采样从密到稀的各种情形。

用到转移检测上不需要转移标签。对一个基因组里的每个基因，模型给出它的归属；如果模型认为这个基因与某一支的关系，比它所在的基因组与那一支的关系更近，它就是外来候选，那一支就是供体。模型从没见过掺入的基因，学不到模拟数据的破绽。

## 模型

- **输入：** 一条蛋白的命中，每个参考蛋白组只留最好的一个，并按科、目、纲、门设上限（4、8、16、32），取满 64 个。这样一个采样很密的类群不会占满名额。
- **每个命中的数值：** 只描述这条蛋白与该命中的比对：归一化的比特分、一致度、两边的覆盖度、E 值、长度比。
- **分类学只以相对关系进入：** 命中两两之间最深共享到哪一级，作为注意力偏置。模型不认识具体的类群。
- **输出一：** 对每个命中，预测这条蛋白与它最深共享到哪一级（0 = 不同域，1 = 同域，2 = 同门，3 = 同纲，4 = 同目，5 = 同科）。
- **输出二：** 这条蛋白挂在分类树哪个节点的单一分布。候选节点是各个命中在六个级别上的祖先，再加一个“比所有命中都高”的根。

## 事先定下的评估规程

以下各项在看到任何真实数据的结果之前写定（2026-11-15）。

**数据划分**

- 测试集一：按纲划分，纲的编号哈希后落在 0 号桶的整纲留出，其中的蛋白不作为训练样本。
- 测试集二：三个基准受体所在的谱系整体留出，其中的蛋白不作为训练样本。具体是与大肠杆菌或军团菌同目的蛋白组，以及与内阿米巴同门的蛋白组。
- 留出的是“查询蛋白”。这些谱系的蛋白组仍可能作为命中出现在其他谱系蛋白的训练样本里。
- 验证集：其余纲里，蛋白组编号哈希后落在 1 号桶的蛋白组。

**有效样本**

检索保留前 1,000 个命中。一个样本只有在“把藏掉的类群从库里拿走再检索，会选出同样的 64 个命中”时才使用：命中列表没到 1,000 条，或者 64 个名额在列表用完之前已经选满。

**干净的阴性**

用与本工具无关的标准选：蛋白含有名称以 `Ribosomal_`、`tRNA-synt_`、`RNA_pol_`、`EFG_`、`GTP_EFTU` 开头的 Pfam 家族（序列 E 值不超过 1e-10）。误报率只在这些蛋白上量，其余蛋白单独报告。

**不靠模拟的转移试验**

取测试集里的一条蛋白，来自蛋白组 A。再取一个与 A 不同纲的蛋白组 B 当“假宿主”。把 A 和 B 各自的谱系藏到同一级，得到一份命中。

- 本源试验：这条蛋白放在 A 里，按 A 的谱系打分。
- 外来试验：同一条蛋白、同一份命中，放在 B 里，按 B 的谱系打分。

两种试验的输入完全相同，差别只在拿哪个基因组当参照。蛋白是真实的，分化是真实的，没有随机突变。按“理论上最多能看出几级差距”分层报告；差距为零的试验原理上分不出，单独列出。

**主指标**

外来试验对干净本源试验的 AUROC，以及干净阴性上误报率为 1% 时的召回率。

**主打分**

`disc`：在所有命中上，“模型预测的共享深度的期望”减去“参照基因组与该命中的共享深度”，取最大值。其余打分（`p1`、`p2`、`top`、`mean5`）只作参考。

**必须一起报告的对照**

对照和模型用完全相同的命中：

- `ai`：Alien Index，本源组取到门一级。
- `hidx`：同样的比较，用比特分之差。
- `lca`：比特分在最高分 10% 以内的命中取最近共同祖先，看参照基因组是否在这个祖先之内。
- `mlp`：同样的输入，每个命中单独判断，没有注意力。
- `nopair`：有注意力，但不给命中之间的分类学关系。

模型如果赢不了 `ai`、`hidx` 和 `lca`，说明它只是重新学出了已有的规则。

## 规程修订（2026-11-15，第一批结果和代码审查之后）

第一批结果出来后，代码审查查出输入里有标签泄漏，第一批的模型数字全部作废。以下修订是在看过那批作废的结果之后做的，所以两个测试集已经不算“没看过”。第二批训练数据里的测试谱系是新的，最终结论以它为准。

**去掉的输入**

- 每个命中所在各级类群的大小、类群里有命中的比例、剩余蛋白组数、列表是否截断。类群大小是在藏掉谱系之后算的，变小的那个类群就是这条蛋白自己的类群，等于把答案给了模型。
- 每个命中所属的域。现在分类学只以命中两两之间的关系进入。

**加的输出**

- 模型另外输出“挂在分类树哪个节点”的单一分布。对应的打分 `node` 是挂在参照基因组谱系之外的对数几率。它不在最初的规程里，按探索性结果报告。

**评估上的修订**

- 按藏到哪一级分层时，阴性只用同一级的本源试验。
- 增加配对统计：同一份命中上，外来试验的得分高于本源试验的比例，只在标记家族蛋白上算。
- “理论上分不出”的试验单列，作为零假设的参照，它的 AUROC 应当接近 0.5。
- 按假宿主在另一个域、另一个门、另一个纲分层。
- 置信区间按留出的纲重抽样，不再按蛋白组。三个基准谱系分别报告，不给合并的区间。
- 标记家族的 E 值按固定的检索空间（10 万条序列）计算；另用只含核糖体蛋白和 RNA 聚合酶的更严标准做一次敏感性检查。

**增加的对照规则（探索性）**

- `ai_adapt`、`hidx_adapt`：本源组取门；门内没有采样时放宽到还有采样的最近一级。
- `ai_near`、`hidx_near`：同上，但不设门这个上限，本源组可以窄到目或科。
- `lca_adapt`：最近共同祖先规则，祖先的深度以“参考库里还有的最近一级”为上限。

## 规程修订（2026-11-16，结论审计之后）

- **去掉配对统计。** 对任何模型输出，参照基因组与命中的关系越远，这两种打分只会越高，所以“同一份命中上外来高于本源”的比例反映的是换了参照，不反映模型。没训练过的模型也能得到很高的值。
- **干净的阴性每个蛋白每一级只算一次。** 原来同一个标记蛋白配三个假宿主算三次。改后报告标记蛋白的个数，并改报 5% 误报下的召回率。
- **所有模型都报告两种打分，并加一个没训练过的模型作为下限。**
- **`ai_adapt` 的说明更正：** 本源组取门；门内没有采样时才放宽。
- **掺入基准上增加对照：** 现有流程的 Alien Index 不做截断；在模型的输入上用流程自己的本源组算规则；Alien Index 的并列用比特分差打破。

## 文件

- `sample.py`、`search.sh`：从参考库抽样蛋白并检索。
- `markers.py`：按 Pfam 家族选出标记蛋白。
- `prep.py`：把检索结果转成数组。
- `placenet.py`：命中的选取、特征和模型。
- `train.py`：训练，报告归属预测在留出谱系上的准确率。
- `trials.py`：上面的转移试验和对照。
- `score.py`、`eval_hgt.py`：给一个真实基因组的每个基因打分，并在掺入基准上与规则比较。
- `report.py`：从结果文件生成 [RESULTS.md](RESULTS.md) 和 `results/final/summary.md`。
- `results/final/`：本文报告的全部结果。`results/part_a/` 是只用三分之一数据时的中间结果，统计口径较旧（含后来去掉的配对统计）。
