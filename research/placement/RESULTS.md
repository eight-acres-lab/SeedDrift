# 归属模型：结果（2026-11-16）

本文件由 `report.py` 从 [results/final/](results/final/) 里的结果文件生成，数字没有手工抄写。全部数字见 [results/final/summary.md](results/final/summary.md)。规程和修订见 [README.md](README.md)。

## 结论

- 只靠自监督的归属任务，模型学到了可用的信号。它远好于没训练过的同结构模型和去掉分类学关系的对照。
- 用它来找外来基因，目前的水平与配置得当的规则大致相当。没有哪一处的结果能证明它优于配置得当的规则。
- 它胜过事先登记的三条规则，但输给后来加的、本源组能随采样情况调整的规则。
- 在三个真实基因组的掺入基准上，用干净的核心基因当阴性时，所有方法没有差别。
- 结果先后经过两轮代码审查和一轮结论审计。第一轮查出标签泄漏，那之前的数字全部作废；审计指出初稿多处结论说过头，本文件是按审计意见重写的。

## 数据和训练

- 从参考库的 17 个类群里抽 729 个蛋白组，每个抽 100 条蛋白。有命中的 72,820 条，对 4,014 万条蛋白的参考库各检索前 1,000 个命中。这一段的数字来自运行日志。
- 训练用 553 个蛋白组、167,184 个样本。
- 测试用两组留出的谱系。“没见过的纲”有 71 个蛋白组、23 个纲。“基准受体的谱系”有 47 个蛋白组，其中绝大多数与大肠杆菌同目，少数与内阿米巴同门，与军团菌同目的一个都没有抽到。
- 模型约 81 万个参数，训练 20 轮。模型大小和训练设置没有调过，每个模型只训练了一次。

## 不靠模拟的转移试验

同一条真实蛋白、同一份命中，按自己的基因组打分算本源，按另一个纲的“假宿主”打分算外来。下表只用第二批检索的蛋白。每格是 AUROC / 5% 误报下的召回率。

| 打分 | 没见过的纲 | 基准受体的谱系 |
|---|---|---|
| 模型，`disc`（事先登记） | 0.89 / 0.56 | 0.94 / 0.73 |
| 模型，`node`（后加，探索性） | 0.89 / 0.66 | 0.97 / 0.85 |
| 不给命中间的关系，`node` | 0.76 / 0.29 | 0.86 / 0.46 |
| 每个命中单独判断，`node` | 0.74 / 0.04 | 0.82 / 0.44 |
| 没训练过的模型，`node` | 0.66 / 0.35 | 0.71 / 0.32 |
| `ai`：Alien Index，本源组固定在门（登记） | 0.75 / 0.17 | 0.72 / 0.00 |
| `hidx`：比特分差，本源组固定在门（登记） | 0.75 / 0.23 | 0.73 / 0.23 |
| `lca`：最近共同祖先（登记） | 0.83 / 0.18 | 0.80 / 0.00 |
| `ai_adapt`：本源组在门，门内没有采样时放宽（后加） | 0.85 / 0.78 | 0.78 / 0.66 |
| `ai_near`：本源组取参考库里还有的最近一级（后加） | 0.94 / 0.86 | 0.93 / 0.76 |
| `lca_adapt`：祖先深度以最近一级为上限（后加） | 0.89 / 0.79 | 0.84 / 0.32 |

- **样本量：** 没见过的纲有 32,051 个外来试验，干净的本源试验来自 88 个标记蛋白（32 个蛋白组、19 个纲）。基准受体的谱系有 33,419 个外来试验，干净的本源试验来自 102 个标记蛋白。这么少的蛋白撑不起 1% 误报这样严的阈值，所以只报 5%。
- **区间的读法：** 下面的区间都是“模型的打分减去另一个打分”的差值的 95% 区间，按 19 个留出的纲重抽样，只在没见过的纲上算。正数表示模型更好。
- **对登记的规则：** `disc` 的 AUROC 高于 `ai`（+0.084 到 +0.189）和 `lca`（+0.023 到 +0.091）。
- **对后加的规则：** `disc` 的 AUROC 低于 `ai_near`（-0.100 到 -0.004）。5% 误报下的召回率上，`disc` 低于 `ai_near`（-0.403 到 -0.107）、`ai_adapt`（-0.313 到 -0.072）和 `lca_adapt`（-0.309 到 -0.106）。换成 `node` 打分，对 `ai_near` 的召回率差值是 -0.321 到 -0.019。
- **基准受体的谱系：** `node` 略高于后加的规则，但这一组实际上只有一个目，没有区间。按谱系分开：与大肠杆菌同目的是 0.97 / 0.87，`ai_near` 是 0.95 / 0.85；与内阿米巴同门的只有 7 个标记蛋白，`node` 是 0.87 / 0.76，登记的 `lca` 是 0.90 / 0.62，下不了结论。
- **训练带来了什么：** `node` 打分减去没训练过的模型，AUROC 的差值是 +0.187 到 +0.280；减去不给命中间关系的模型是 +0.076 到 +0.201。
- **这张表的系统偏差：** “理论上分不出”的试验，AUROC 应当是 0.5，实际 `disc` 是 0.62 和 0.70，`ai` 是 0.63 和 0.77。原因是外来试验来自全部蛋白，本源试验只来自标记蛋白。所以 0.1 以内的 AUROC 差别不宜解读，`disc` 对 `lca` 的优势就落在这个范围里。
- **并列的影响：** Alien Index 有上限，很多本源试验并列在最高值。按“并列算打分输”的约定，`ai`、`lca` 等规则的召回率是在比 5% 更低的实际误报率下读的，是下界。

## 掺入基准

三组基准见 [docs/benchmark-results.md](../../docs/benchmark-results.md)。模型从没见过掺入的基因。这整套比较不在最初的规程里，是事后做的。

先看干净的阴性。下表是只拿核心基因当阴性的平均精确率：

| 打分 | 大肠杆菌 | 内阿米巴 | 军团菌（DNA 移植） |
|---|---|---|---|
| 现有流程的规则 | 0.979 | 0.958 | 0.983 |
| 现有流程的 Alien Index，不做“是否判为外来”的截断 | 0.983 | 0.963 | 0.988 |
| 特征模型，用其他受体的掺入数据训练 | 0.983 | 0.959 | 0.988 |
| Alien Index，用模型的输入和流程的本源组 | 0.981 | 0.917 | 0.988 |
| 比特分差，用模型的输入和流程的本源组 | 0.981 | 0.871 | 0.989 |
| 归属模型，`disc` | 0.982 | 0.961 | 0.989 |
| 归属模型，`node` | 0.983 | 0.959 | 0.990 |
| 不给命中间的关系，`node` | 0.979 | 0.916 | 0.989 |
| 没训练过的模型，`node` | 0.950 | 0.705 | 0.972 |

再看把所有非掺入基因都当阴性的平均精确率。这些基因里有真实的转移基因，所以这张表衡量的不只是对错：

| 打分 | 大肠杆菌 | 内阿米巴 | 军团菌（DNA 移植） |
|---|---|---|---|
| 现有流程的规则 | 0.772 | 0.546 | 0.859 |
| 现有流程的 Alien Index，不做“是否判为外来”的截断 | 0.788 | 0.553 | 0.873 |
| 特征模型，用其他受体的掺入数据训练 | 0.776 | 0.706 | 0.886 |
| Alien Index，用模型的输入和流程的本源组 | 0.781 | 0.414 | 0.884 |
| 比特分差，用模型的输入和流程的本源组 | 0.759 | 0.452 | 0.904 |
| 归属模型，`disc` | 0.690 | 0.726 | 0.913 |
| 归属模型，`node` | 0.801 | 0.718 | 0.917 |
| 不给命中间的关系，`node` | 0.715 | 0.523 | 0.838 |
| 没训练过的模型，`node` | 0.535 | 0.091 | 0.676 |

- **用核心基因当阴性，现有流程和归属模型没有差别。** 内阿米巴上，放过 11 个核心基因时，现有流程的 Alien Index 召回 80%，模型的 `node` 召回 80%。
- **把所有非掺入基因当阴性，`node` 在三组上都高于现有流程的规则**（差值的 95% 区间：+0.01 到 +0.05；+0.14 到 +0.20；+0.03 到 +0.09）。但这个差别的含义不清楚：排在掺入基因前面的“误报”，在大肠杆菌里主要是原噬菌体基因，在内阿米巴里多是很可能真实的细菌来源基因。
- **事先登记的 `disc` 在大肠杆菌上显著更差**（0.690 对 0.772）。六种读出方式在同一个基因组上的差别，比模型与规则之间的差别还大，而 `node` 是看过结果之后才加的。
- **在两个细菌受体上，简单的规则就能达到模型的水平。** 大肠杆菌上，现有流程的 Alien Index 去掉截断就是 0.788，模型是 0.801。军团菌上，比特分差的规则是 0.904，模型是 0.917。
- **内阿米巴上，规则用模型的输入时很差**（0.414 和 0.452），即使本源组和流程一样取变形虫界。一个可能的原因是模型的输入只留 64 个命中：保守基因的名额被其他门的强命中占满，变形虫界的弱命中进不来，规则就以为本谱系没有同源；现有流程有专门的本谱系补搜，不受这个影响。这个解释没有验证。无论原因是什么，这一行不能说明模型比规则强。
- **训练是必要的。** 没训练过的模型在内阿米巴上只有 0.091。

## 数据量

在同一批转移试验上比较用三分之一数据和全部数据训练的模型（AUROC / 5% 误报下的召回率，`node` 打分）：

- 没见过的纲：0.90 / 0.71 → 0.89 / 0.66，没有提升。
- 基准受体的谱系：0.95 / 0.77 → 0.97 / 0.85，有提升。
- 掺入基准（全部非掺入基因当阴性）：大肠杆菌 0.788 → 0.801；内阿米巴 0.718 → 0.718；军团菌（DNA 移植） 0.916 → 0.917。
- 每种数据量只训练了一个模型，没有区间。数据量的作用因谱系而异，目前说不清。

## 局限

- 所有阳性都是构造的，没有一个自然发生的转移。
- 转移试验的干净阴性只有标记家族的蛋白（核糖体蛋白、氨酰 tRNA 合成酶、RNA 聚合酶等），数量少，而且规则在这类蛋白上本来就表现好。分布零散的基因上谁更好，量不出来。
- 掺入基准里除核心基因外没有干净的阴性；核心基因又太容易，分不出方法的好坏。
- 与现有流程的比较里，检索方式和打分方式同时不同：流程用前 100 个命中加本谱系补搜，模型用前 1,000 个命中里按类群分层选出的 64 个。
- `node` 打分、`ai_adapt`、`ai_near`、`lca_adapt` 和整套掺入基准的比较都是看过部分结果之后才加的。两个测试集和三个基准基因组都不止看过一次。
- 基准受体谱系那一组几乎只有一个目。

## 下一步的候选

- **先解决评估。** 没有干净的阴性和真实的阳性，就分不出“与规则相当”和“比规则好”。这回到之前讨论的标签问题。
- **给模型规则没有的信息。** 现在模型和规则读的是同样的每个命中的汇总数值。从比对里读出命中两两之间的距离，是方案评审认为最可能突破上限的一步。
- **去掉 64 个命中的限制对本谱系的影响。** 例如给本谱系的命中保留名额，或者把本谱系补搜的结果也放进输入。
- **事先登记好一个读出方式，再在没用过的受体上检验。**
