# W12: the second, larger training set of tables of version 1

- `rel_w12_v1.name` names a table set (default w12-<which>-r<rows>-s<seed>). Profile rel-dev-w12-v1-k3-400k-i1 builds
  403,200 training tables (33,600 per group) from the same search, seed and code as rel-dev-w12-v1-k3-i1: a table
  depends on its number alone, so its first 201,600 tables are that set's byte for byte (a test checks the prefix), and
  its 3,000 held-out tables are the same.
