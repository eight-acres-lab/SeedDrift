# W18: implant tables (a ruler set) and the readouts read on them

- `bench/rel/implant.py`: the first ruler set of the relational line. A triple is three tables of a held-out examined
  genome A at the locus of one of its genes i, with the same rows: the implant (the target block holds a gene j of
  another held-out genome D of the standard code), the original (A:i) and the own control (another gene k of A, not a
  neighbour, not a relation block). Rows are training genomes with a homolog row on all three target genes, so the three
  tables have the same rows with content on the target; D is never a row; donors are drawn by the tier of their
  distance to A in turn; lengths are matched. Imports the table code of W2 (only imports it).
- Stage `w18_rulers` (`ci/stages/rel/w18_rulers.py`, rule in `ci/rules/rel_w18.smk`): the implant tables from a passed
  selfsup run and a passed distance run of W2, every file checked against its records, the sealed check first; the
  genetic code from the corpus spec and the NCBI taxonomy (both 1 or 11). Kind ruler, purpose ruler; W18's meta (row
  tiers, donor distance, host codon counts, ...) in one `w18_meta.npz` beside the shards, never a model input.
- `seeddrift/train/rel/readouts/w18_passes.py` (numpy, both interpreters): the model passes of the readouts (scattered
  target and context, each with one distance tier of rows removed; the whole target and its two halves; the target
  without relatives; the same with the other rows' content hidden), a loop that renders and scores them through the
  caller's renderer and model, the per-cell file, and `run_ruler`, the entry the evaluation stage of W6 calls.
- `seeddrift/train/rel/readouts/w18_readouts.py` (numpy): source shift, the two-block gain with its calibration,
  composition, abstention, the classical controls (best similarity, rows on the target, host codon usage) and the AUCs
  per group and block with a genus bootstrap.
- Tests `tests/ci/test_rel_w18_implant.py`, `test_rel_w18_readouts.py`, `test_rel_w18_stages.py`.
