# 难基准：全场景的水平基因转移评估

旧基准只测了最容易的一格（细菌与真核之间的跨界转移），所有像样的方法在那里都打平。这套基准把范围扩到真正高发和真正容易出错的场景，并且让每个结论都有对照。

- 操作规程（首次冻结）：[PROTOCOL.md](PROTOCOL.md)
- 完整设计、各阶段、评审补丁：[DESIGN.md](DESIGN.md)
- 训练时必须排除的类群：[EXCLUDE.tsv](EXCLUDE.tsv)

## 和旧基准有什么不同

| | 旧基准 | 难基准 |
|---|---|---|
| 阳性 | 随机替换过的外来蛋白 | 真实基因组岛基因；未改动的真实基因和可移动元件拼接进真实染色体 |
| 阴性 | 核糖体等标记基因，或没有标签的“其余基因” | 位置核心基因：在同属其他物种里保持原位的单拷贝基因，由方法看不到的同属基因组认定 |
| 近缘参考 | 隐藏同属（按名字） | 隐藏同属以及实测一样近的参考；另有“整科隐藏”的口径 |
| 阈值 | AUROC、5% 误报 | 1% 认证阴性被判外来时的召回率，并列按期望计 |
| 邻域信息 | 只有组成打分用了 | 每个打分都用同一个窗口再评一次 |
| 对照 | 无 | 9 个平凡打分（基因长度、有同源的参考个数等），任何方法必须全部赢过 |
| 统计单位 | 基因或染色体 | 属；按属配对，精确置换检验 |

## 三层数据

- **开发集（随便看）**：基因组岛参考集里的 24 条肠杆菌染色体，以及旧基准的全部数据。所有参数都在这里定。
- **测试集 A**：其余 18 个属里的 13 个（够数时）或全部。第一阶段末打开一次，第二批构造场景做完后再打开一次，每次都有日志。
- **保留集 B**：够数时留出 5 个属，在第一个读 DNA 的模型冻结之前，任何方法都不在上面打分。

封存的是“分数与标签的对接”。检索、标签、分数本身可以提前算好。

## 主要终点

- **P1（1a）**：真实岛基因，单基因级，1% 位置核心被判外来时的召回率。比较：密码子对宽表模型；融合对密码子；宽表模型对四条线性规则（必须全部赢过）。
- **P2（1a）**：真实岛区段，区段级。比较：加窗口的密码子对加窗口的宽表模型；加窗口的融合对加窗口的密码子。
- **P3（1b）**：差异丢失造出的难阴性（M8）上，判定率涨了多少，以及还能不能把它和做了同样删除的近缘供体基因分开。
- **P4（1b）**：拼接的单基因转移，按供体远近四档分别报告。
- **P5（1b）**：整段拼入的宿主匹配原噬菌体。

## 一个差别怎样才算数

“A 比 B 好”需要同时满足：区间不含 0；差值至少 0.05；多重校正后 p 小于 0.05；在三个针对已知标签偏差的分析里方向一致；涉及相似性的方法在“整科隐藏”下方向也一致；跨输入类别的比较在“只用深层本源基因定阈值”时也成立；并且 A 赢过每一个平凡打分。读两种输入的方法还必须赢过“密码子加一个平凡相似性代理”的融合。其余一律报告为“未分辨”。9–13 个属只能分辨约 0.08 以上的差别。
