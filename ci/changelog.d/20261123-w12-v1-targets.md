# W12: target genes of the tables of version 1

- Tables of version 1 take each genome's target genes in a shuffled order (one order per genome, from the seed): a gene
  is the target again only after every gene of its genome has been one (the programme lead, 2026-11-23, for the larger
  first training set); the manifest records, per part, the tables, the distinct targets and the most times one was used.
- Stages w12_search and w12_v1 read a source run without stage pairs (the corpus of stage rel_w13_build).
- `rel_w12_v1.frame_index` (none, target, all): the table set also carries the pairs of the search's index that
  align.frame_layout_online looks up for its tables (v1_hits.write_subset: same layout and answers for those pairs), so
  a machine that trains on the tables needs that subset, not the whole index. The coverage names the close relatives of
  a corpus built by W13.
