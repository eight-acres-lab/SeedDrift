SeedDrift

看看基因组里哪些基因像是从别的田里飘来的种子：来自哺乳动物、原核生物，还是别处

新的分析

支持蛋白或 CDS 的 FASTA、GenBank / EMBL、GFF3（含或另附基因组序列）、基因组 contig（原核用 pyrodigal、真核用 MetaEuk 预测基因）；可以是 gz / bz2 / xz。文件经由你的网络上传。

由服务器直接下载，不占用你本地的流量。

本谱系范围越窄，越近的转移也会被判为外来（例如选“科”时，来自同门其他科的基因也算）。

分析记录

    从左边开始

    上传一个基因组，或者选一个示例。每个基因都会和约 4,000 万条 UniProt 参考蛋白比对， 再按 Alien Index 判断它离本谱系近还是离外部谱系近，并去掉重复结构造成的假信号。

    结果是候选，不是定论：相似性本身不能区分转移、古老保守和参考库污染。
