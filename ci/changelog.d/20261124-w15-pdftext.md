Package W15: `bench/rel/registry/pdf_text.py`, a standard-library PDF text extractor for any PDF supplement, and stage
`w15_registry` item 7. The extractor reads plain objects and object streams, decodes FlateDecode, LZWDecode,
ASCIIHexDecode, ASCII85Decode and RunLengthDecode, and takes the text operators (Tj, TJ, ', ") also inside form
XObjects. Characters come only from what the file states (a ToUnicode map; a named encoding with its Differences, glyph
names by the Adobe naming rules; Standard encoding for the non-symbolic standard 14 fonts); any other code comes out as
U+FFFD. A page gives text only when at least 0.95 of its characters are readable and, with 20 or more letter words of
four letters or more, at least 0.75 of them contain a vowel or a non-ASCII letter; every other page gives its reason
and no text. An encrypted file or one whose structure cannot be read is unreadable as a whole. With
`pdf_text: {from_run, files}` the stage reads only PDFs a passed registry run stored: the source report must be the
output its stage recorded and each file must match the recorded sha256 (archive members through the archive's); the
gate fails on a file not stored, ambiguous, changed or not read, not on an unreadable PDF. Profile
`rel-dev-w15-pdftext-i1`; request `configs/rel/requests/20261124-w15-pdftext.yaml`.
