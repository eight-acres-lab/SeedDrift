# W13: the build of corpus medium-k3x in parts that take nothing from each other; the corpus stage in processes

- Stage corpus: profile block `corpus.processes` (default 1) builds the genomes in that many processes, each genome
  alone, the manifest in the spec's order: the same files and manifest as with one (test in test_rel_w13_xpick.py).
- `python -m ci.stages.rel.w13_build part I N CORPUS RELATIVES --only`: the corpus spec of part I alone (the corpus's
  earlier genomes and that part's relatives), so the search runs of the parts reuse only the earlier corpus's run and
  can run in any order; the run of the whole spec reuses all of them.
- Corpus specs medium-k3x-part1of5 ... part5of5 (each the 1,772 genomes of medium-k3 and about 1,340 of the 6,700 new
  ones, about 168,000 new proteins) and profiles rel-dev-w13x-search1-i1 ... search5-i1 (upto search, 12 threads, the
  corpus in 12 processes, reuse from run B of medium-k3 only). The run of the whole spec (upto all: train_data and the
  checks) follows when the five have passed.
