# W12: training targets drawn over the whole group; the use of targets reported (stage w12_tstats)

- `rel_w12_v1.train_sampling: gene` (the programme lead, 2026-11-23): the training tables' targets are drawn over all
  the genes of a group without replacement (v1_build.plan_by_gene), every gene once before any twice; the groups keep
  equal shares; the held-out tables are drawn as before (the same tables). The default stays `genome`. The manifest
  reports per group the genes that can be a target, distinct targets, mean and most uses, the share of tables whose
  target is used ten times or more and their genomes, and the share of tables by relation (anchor, same species, same
  genus). Profile rel-dev-w12-v1-k3-400k-i1 uses it.
- Stage `w12_tstats` (`ci/stages/rel/w12_tstats.py`): the same report for a table set already built (the 201,600 tables
  of round 1).
- `rel_w12_v1.heldout_equals: {run, sha256}`: gate G4_rel_w12_v1 hashes every held-out file of the set again and fails
  unless each is the file of the reference set (run, manifest sha256) with the same name and sha256, naming the files
  that differ (the programme lead, 2026-11-23: round 2's held-out tables are round 1's, byte for byte).
- `rel_w12_v1.max_uses_per_target` (with train_sampling gene): a group takes at most that many training tables per gene
  that can be a target (min(per group, K x genes)); the tables it leaves go to no other group; the manifest gives each
  group's tables (the programme lead, 2026-11-23: K = 5 for the 400k set; eukaryotic viruses have 1,804 genes).
